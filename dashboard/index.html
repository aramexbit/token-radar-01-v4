How the value is fitted

The model fits log market cap on log TVL across live-token protocols, one line per category where the data allows it, shrunk toward the global line, and reads each pre-token protocol through its category’s line — bent by its 7-day TVL move (×0.8–1.2) and by how long it has run with no token (×0.85–1.0), capped at 10× TVL.
